# リメイク Block 1 分割実装（全5パート）

Daily Tower のフロア1〜10をリメイク案の内容に置き換える作業を、5パートに分けて実装しています。このファイルがあなたの担当パートの指示です。書かれていることだけを実行してください。

共通ルール：
- 変更は src/extensible/ 配下のみ。**src/core/ は変更禁止**。
- ゲーム内UIに開発者向けの文言や更新履歴を入れないこと。
- 完了条件：npm test 全件パス、npm run build 成功、その状態で main へ push すること。
- 完了報告に、変更ファイル一覧・テスト／ビルド結果・指示から変えた点（あれば全部）を書くこと。

## パート1/5：敵10種とスプライトの登録

- 下記の通常敵8種・ミニボス2体を src/extensible/enemies/enemyRegistry.ts に登録する。
- moss_slime / forest_goblin / shadow_wolf / vine_stalker は既存エントリの**同ID再定義**（ステータス・弱点・耐性・フェイズ・スプライト指定を下記で置き換え）。他は新規追加。
- 新規スプライト5種（thorn_sprout / bark_beetle / forest_wisp / vine_stalker / amber_golem）のマトリクスとパレットを spriteRegistry / matrixRegistry に登録する。流用指定の敵は既存の spriteId / palette を使う。goblin_chieftain は既存 goblin マトリクス＋新規パレット crimson_chieftain。
- **vine_stalker のマトリクスは31行しかない。末尾に全て0の行を1行追加して32行×32要素にすること**（図柄は21行目までで完結している）。
- フロアデータ・アイテム・イベントはこのパートでは変更しない。
- コミットメッセージ：`[CF-Pages-Skip] Remake Block 1 (1/5): enemies and sprites`
