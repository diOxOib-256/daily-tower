## 実装内容

### 1. 新規敵1体（src/extensible/enemies/enemyRegistry.ts）

parchment_wraith（羊皮紙の亡霊 / Parchment Wraith）
- HP 68 / ATK 15 / DEF 4
- weakness: 'fire' / resistance: 'ice'（Doc 案の resistance 'void' から変更。理由は下記「属性の原則」参照）
- spriteId: 'parchment_wraith', palette: 'parchment_wraith'
- goldReward は書かないこと。2026-11-16 のエンジン改修により、未指定ならステータスから自動算出される（通常 = round((HP + 2×ATK) / 12)。この敵なら 8G になる見込み）。
- 全アクションに logMessage を必ず書くこと（ゲーム内の口調で短く）。フェーズは hpThresholdPercent 降順。
- Phase 1 (100):
  - 紙片の旋風 (type: attack, weight 60, damageMultiplier: 1.0, logMessage: '羊皮紙の亡霊が鋭利な紙片を飛ばして切り裂いた！')
  - 魔導インクの呪縛 (type: debuff, weight 40, statusId: 'def_debuff', statusValue: 15, statusDuration: 2, logMessage: '羊皮紙の亡霊が呪いの文字を浮かび上がらせ、防御力を下げた！')
- Phase 2 (45):
  - 禁書乱舞 (type: 'debuff' とすること。Doc 案では type: attack と書かれているが、CombatEngine は statusId を type 'buff'（自身へ）または 'debuff'（プレイヤーへ）の場合にのみ適用し、type 'attack' の statusId は無視される。ダメージ＋状態異常の行動は既存の慣例（ink_phantom の「染み込む闇」や glass_sentinel の「破砕の乱撃」と同型）どおり type: 'debuff' ＋ damageMultiplier とすること。weight 70, damageMultiplier: 1.35, statusId: 'poison', statusValue: 3, statusDuration: 2, logMessage: '羊皮紙の亡霊が毒を帯びた古文書で連続攻撃を仕掛けた！')
  - 頁の防壁 (type: buff, weight 30, statusId: 'shield', statusValue: 12, statusDuration: 2, logMessage: '羊皮紙の亡霊が幾重にも頁を折り重ね、障壁を張った！')

属性の原則の確認（Doc 案からの修正1）：Realm 2 のフロア報酬武器は stargazer_silver_sword（void）と astral_quill（fire）のみである。Doc 案の resistance 'void' は Realm 2 の報酬武器属性と一致するため、ルールタブ §3 の属性の原則に反する。resistance を 'ice' に変更する（ice 属性の武器は Realm 2 の報酬プールになく、chronos_moth / void_scribe / tome_warden と同じ前例）。weakness 'fire' は astral_quill で突けるため Doc 案どおりで変更なし。
なお既存の living_tome（resistance 'void'）はパイロット時代からの既知の逸脱であり、今回の対象外である。変更しないこと。

既存の敵（living_tome / ink_phantom / brass_astrolabe / chronos_moth / void_scribe / astral_owl / glass_sentinel / tome_warden）の weakness / resistance は変更しないこと。今回の対象は parchment_wraith のみ。

### 2. 新規アイテム1種（src/extensible/items/itemCatalog.ts、フィールドは既存の同種定義に倣う）

astral_storm（星屑の嵐, skill）
- category: 'attack', targetScope: 'all_enemies', maxChargesPerBattle: 2
- damageMultiplier: 0.85
- applyStatus: { target: 'enemy', statusId: 'def_debuff', value: 20, duration: 2 }（Doc 案の value 15 から 20 に変更。理由は下記「支配関係」参照）
- salvageGold: 8（同じ全体攻撃スキル flame_wave と同額）
- spriteId: 'item_astral_storm'（Doc 案の spriteId 'astral_storm' ではなく、スキルアイコンの既存慣例 item_* に倣う。item_flame_wave / item_void_barrier と同じ形式）
- description: '虚空から無数の星屑を降り注がせ、敵全体に0.85倍ダメージを与え防御力を20%低下(2T)させる範囲攻撃（1戦2回）。'
- 形式は既存の全体攻撃＋状態異常スキル（ember_storm_sweep / whirlwind_slash / leyline_storm）に倣うこと。targetScope 'all_enemies' と applyStatus の組み合わせはこれらの前例どおりに実装できる。

支配関係の確認（Doc 案からの修正2）：Doc 案の astral_storm（全体 0.85倍＋def_debuff 15/2T・回数2）は、既存スキル leyline_storm（霊脈の嵐刃、デビュー 42F、全体 0.85倍＋def_debuff 15/2T・回数2）と全軸で数値が完全一致する「同性能の別名品」になる。スキル一覧の検証基準（同一系統内の数値の完全一致 0件）およびルールタブ §7 チェック3に反するため、def_debuff を 20 に引き上げて実装すること。これにより同系統（全体攻撃＋def_debuff）の階段は whirlwind_slash（0.85倍＋def_debuff 10、デビュー 22F）→ leyline_storm（0.85倍＋def_debuff 15、デビュー 42F）→ astral_storm（0.85倍＋def_debuff 20、デビュー 57F）と単調になる。def_debuff 20 の前例は corrosive_haze（0.7倍＋def_debuff 20/2T）がある。
なお Doc 案のセルフチェックにある「51〜56Fの既存スキルはすべて単体または自己バフ」は誤りである。flame_wave（炎の波動、デビュー 51F）は全体攻撃 0.8倍・回数2 の既存スキルであり、astral_storm はその次の階段（0.85倍＋def_debuff 付与）として成立する。重複ではない。

数値バンド（AGENT_GUIDE §2.8、Realm 2 step 2）：全体攻撃の倍率上限は 0.85 であり、astral_storm の 0.85 は上限ちょうどで適合する。def_debuff の値・持続は上記前例の範囲内。maxChargesPerBattle 2 は 1〜3 の範囲内。

Doc 案の Card 1「星屑のペン先（astral_quill）」と Card 3「司書の守護章（guardian_crest）」は既存アイテムの流用である。新規アイテムとして登録してはいけない。astral_quill は itemCatalog に登録済み（武器 ATK 18 / fire）。guardian_crest はカタログ ID 'guardian_crest_relic'（effectId 'guardian_crest'、戦闘開始時に最大HPの15%のシールド。Doc 案の「shield 10」は概数であり、既存定義どおりで変更なし）。
